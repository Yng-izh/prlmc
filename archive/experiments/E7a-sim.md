## E7a-sim — 阶段 A 收尾：内容相似度 vs 功能干扰的判读

### 目的

E7_PLAN 阶段 A 的最后一个判读项（63–70 行）：语义相似度能否预测功能
干扰/兼容性。能 → 内容路由有机制基础；无关 → 停止门槛 1 触发，
不做语义 router。这是阶段 B 之前的分岔点。

### 配置

| 项 | 值 |
|---|---|
| 表征 | 冻结 MemoryLLM reader 最后一层 hidden state 的 mean-pool，逐行编码 8 窗内容（anchor 30 行 + 窗口主体 500 行/窗，共 4240 行） |
| 纯文本路径 | checkpoint 的 `initialized=1` 会使前向拼接 12824 slot memory 池并崩溃（23 vs 12824 错位）；复位 `initialized=0` + `lm_head→Identity`（消除 B×T×128k logits 分配）后为纯文本编码 |
| 对比信号 | 梯度余弦（8×8）、24 步功能 delta/rescued/harmed（seed 0 报告） |
| 运行 | v100-2 双卡分片（GPU0+1，device_map=auto，每卡承担一半权重；单卡 16GB 被宿主机进程挤占放不下） |
| 脚本 | `tools/e7a_similarity.py` |

### 结果

**1. 内容相似度带宽几乎为零。** 8 窗两两余弦全部落在 0.9976–0.9991
（mean 0.9984，sd 0.00034）。同一 context（row 3）的 8 个窗口在 reader
表征空间里是**同一个点**：最高对 14470–14850（0.99906）与最低对
16750–17510（0.99763）相差不到 0.15%。E7 计划预告的"同 context 相似度
带宽窄"以极端形式兑现——不是"窄"，是"平"。

**2. 内容相似度不预测任何功能信号。**

| 信号 | pearson | spearman |
|---|---|---|
| 内容 vs 梯度余弦 | 0.028 | −0.090 |
| 内容 vs 功能 delta | −0.374 | −0.424 |
| 内容 vs rescued | −0.251 | −0.336 |
| 内容 vs harmed | 0.188 | 0.189 |
| 梯度余弦 vs 功能 delta | 0.197 | 0.236 |

负相关（delta/rescued）来自矩阵第 4 个小数位上的抖动，非实质信号；
有效判读是"无相关"。梯度余弦对功能 delta 的预测力（0.197/0.236）
也仍属弱。

**3. 聚类一致性为随机水平以下。** ARI：k=2 为 −0.149，k=3 为 −0.143。
内容聚类与功能聚类连方向都不一致。

### 判读：停止门槛 1 触发

**在这个 fixture 上，内容路由没有机制基础。** 判据链条：

1. 内容表征带宽 0.0015 —— 输入侧没有可供 router 消费的信息。8 窗内容
   在 reader 表征空间几乎重合，任何基于内容的路由函数拿到的都是
   同一个输入，输出必然塌缩。
2. 内容相似度与功能干扰零相关（|r|≤0.42 且方向不稳）—— 即使强行
   分簇，簇结构与干扰结构无对应。
3. E7_PLAN 68–70 行的判读原文："若二者无关，不能用语义 router 声称
   在分知识，应考虑按功能梯度或预测变化路由，或停止专家方向。"

**结论的性质与边界：** 这是对"单 context fixture"的判决，不是对内容
路由的全局死刑。8 窗全部来自 row 3 同一篇文章的事实序列，事实类型
（人物-国籍、机构-城市）高度同质。跨 context（不同 row）的带宽
未测——但当前 E7 计划在阶段 B/C 之前不会换 fixture，所以在当前
实验轨道内，这条停止门槛触发。

**修正后的阶段 B 进入方式：**

- B2（expert-oracle）与 B3（expert-random）的解释权重大幅上调：内容
  无信号时，oracle 只剩"窗口身份"可用，即 B2 测的是**纯窗口隔离**
  （每窗一个专家），与内容无关。
- 停止门槛 1 的原文动作"考虑按功能梯度路由"成为 C 阶段唯一存活的
  router 候选（如果 B2 显示隔离有价值）。
- B0/B1 的 3-seed interleave 数据已齐（+24~+30），基线就绪。
