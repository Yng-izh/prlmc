# 00 目标、主张与方法演进

## 冻结的目标与主张

- **目标**:不大改论文主线,通过调节内部架构得到强泛化性的稳定涨点。
- **主张**:相同、有限的潜在记忆容量下,跨块信息能提高长文档中知识的保留与可读取能力。
- **核心指标**:`Ours − Selection`。两臂共享写入流、载体块、容量、解码与评分,只差压缩算子。
- **评测方式**:算子训练后冻结,不做逐场景训练;在公开原始任务上逐题生成并评分。

## 当前判断

1. 收益的主体是**全池残差校准**,不是选槽,也不是"融合"。
2. V13 的内容因果成立(换别人的 graft 掉 13 题,p=0.024),但"跨块邻居"本身没有显著贡献
   (随机邻居只低 5 题,p=0.18)。论文主张里"跨块融合"这一句目前证据不足。
3. 所有数字是单种子、同一批 158 题。下一步要独立数据集与多 seed,见
   [06-experiment-ledger.md](06-experiment-ledger.md) 第四节。
