# 06 实验总表(截至 2026-11-16)

本页是**一页看全**的出口:每个版本改了什么、答对多少、结论是什么、为什么留或淘汰。
更细的早期实验见 [03-results.md](03-results.md)。

## 评测设置

- 数据:LongBench 里的 HotpotQA,200 行中 **158 行**够 19 块,其余排除。
- 冻结 MemoryLLM-8B,单次 19→9 压缩,容量 2,304 槽,所有臂共用同一组载体块。
- 评分:官方 QA F1,**F1 ≥ 0.5 记对**。
- 显著性:精确双侧 McNemar,只算在"救回 / 弄坏"两个配对计数上。
- 训练集:MuSiQue,384 更新,seed 0。
- **全部数字是单种子、同一批 158 题。** 这 158 题已被反复用来选机制和超参。

## 一、主结果

| 臂 | 答对/158 | 说明 |
| --- | --- | --- |
| Full | 47 | 19 块不压缩,上限参照 |
| Selection | 35 | 只保留 9 个载体块,基线 |
| Graft(V10) | 41 | 同块原生槽测地压缩嫁接 360 槽 |
| AnchorOnly | 56 | 只校准 360 个锚点,删掉候选路径 |
| V11Evict | 61 | 1,620 载体槽 + 684 被删块槽,全池残差校准 |
| V11EvictDonor | 57 | 同上,684 槽换成上一题文档的 |
| **V13** | **67** | V11Evict 窗口 + 跨块 top-4 邻居条件校准 |
| V13Donor | 54 | 同上,graft 换成别人的 |
| V13RandNeighbor | 62 | 邻居换成随机跨块槽位 |
| V13BottomNeighbor | 62 | 邻居换成相似度最低的 |
| V13Density(V17) | 66 | V13 上不训练,按块内冗余重分配 core 配额 |

Full 只有 47,V13 的 67 超过了它。Full 是不压缩的 reader 上限,可能说明这里的收益不是"保住了更多原文",
而是校准把 reader 的读出推向了更对的方向。这是推测,没有直接验证,需要独立数据集确认,不能直接当成论文结论。

## 二、配对检验(158 题)

| 对比 | 救回 / 弄坏 | 净值 | p |
| --- | --- | --- | --- |
| Graft − Selection | 11 / 5 | +6 | 0.21 |
| AnchorOnly − Graft | 23 / 8 | +15 | 0.011 |
| V11Evict − AnchorOnly | 16 / 11 | +5 | 0.44 |
| V11Evict − V11EvictDonor | 16 / 12 | +4 | 0.57 |
| V13 − V11Evict | 7 / 1 | +6 | 0.07 |
| V13 − AnchorOnly | 19 / 8 | +11 | 0.052 |
| V13 − V13Donor | 21 / 8 | +13 | 0.024 |
| V13 − V13RandNeighbor | 7 / 2 | +5 | 0.18 |
| V13 − V13BottomNeighbor | 18 / 13 | +5 | 0.47 |
| V13Density − V13 | 0 / 1 | −1 | 1.0 |
| V16 − V13 | 0 / 4 | −4 | 0.125 |

读法:
1. **V13 的内容因果成立**(换成别人的 graft 掉 13 题,p=0.024)。这是当前最强的一条证据。
2. **V13 比 V11Evict 多出的 6 题还不显著**(p=0.07)。
3. **"跨块邻居"本身的贡献没有被证明**:随机邻居和最差邻居都只低 5 题,p 分别为 0.18 和 0.47。
   也就是说 V13 比 V11Evict 好,可能一部分来自校准器加了一个有容量的条件分支,而不只是邻居选得对。
4. V11Evict 的 donor 检验(+4,p=0.57)在这一轮重训后没有再现,早期报告里的 +8(p≈0.13)
   来自旧权重。V13 的 donor 检验更强。

## 三、版本逐个说明

### V10:保流形槽位嫁接(基线)
- 改了什么:每个输出块 216 核心槽(逐位复制载体)+ 40 嫁接槽(同块内被丢弃槽的测地压缩,保范数)。
- 结果:HotpotQA 41(对 Selection +6,p=0.21)。LongBench v2 上与原生基线统计不可区分。
- 结论:保留作基线。设计见 [01-method-v10.md](01-method-v10.md)。

### 实验 1 到 8:机制排查(详见 [03-results.md](03-results.md))
| 实验 | 问题 | 结论 |
| --- | --- | --- |
| 1/2/3 | 删槽、插槽、重排各自的损伤 | 删槽中性,插槽净赚,重排贡献小 |
| 1B | 学习式多对一融合 | 读出距离降 20%,准确率反而降,CE 与准确率解耦 |
| 2 | 来源端浓缩 | +10pp,但反事实消融证明不来自候选内容 |
| 3/4/5 | Anchor-Only、Key-Safe、K/V 通道交换 | 收益是锚点校准;内容主要走 key 通道,但改 key 会破坏已有知识 |
| 6 | 容量让给被删块 | 单调退化(−1,−7) |
| 7 | V11:折叠 vs 淘汰 | 折叠删除,淘汰留下(61) |
| 8 | V12 桥接路由 + 动态容量 | 47 / 41,都低于基线 56,判定停止 |

### V11Evict:Reader 效用选槽 + 等容量淘汰 + 全池校准
- 窗口:载体块里按 Reader 效用取前 180 槽共 1,620 个;被删块里按效用 × 新颖度 + MMR 选 684 个。每槽逐字复制,用 `torch.equal` 校验。
- 结果:61。选槽本身只值 3 题(41→44),校准值 17 题(44→61)。
- 结论:窗口保留为 V13 的底座。可调的收益在校准,不在选槽。

### V13:跨块条件化校准(当前最好)
- 改了什么:只改校准器。校准某个槽位时,读取其他块里 Reader key 余弦最高的 4 个槽位的**内容**作为条件,
  注入有界低秩残差。邻居不被平均或替换。校准器零初始化,step 0 等于 V11Evict。
  残差上限 core 0.15 / graft 0.50,正则权重 2.0 / 0.5。
- 默认学习率下只有 61(与 V11Evict 持平)。`--cross-lr 3e-3` 后得到 67,这个超参是在同一批 158 题上看着选的。
- 评测对象:`runs/cross_block/cross_lr.pt`,报告 `reports/cross_block/eval_v13_lr.json`。
- 限定:单种子;无独立验收集;超参在测试集上选。

### V13 的消融与变体(都未超过 V13)
| 版本 | 改了什么 | 答对 | 结论 |
| --- | --- | --- | --- |
| V13 graft 缩放 0.38 / 0.40 / 0.42 | 推理时缩小 graft 残差 | 63 / 65 / 65 | 缩放无增益 |
| V13RelevanceCap | 按相关度限幅 | 64 | 无增益 |
| V14 complement | 邻居改成 2 个同类 + 2 个异类,每组等权重 | 65 | 比 V13 低 2,判定线(≥+4)未达到,报告已清理 |
| V15 LSRM | 每层独立 top-4,sink,"邻居减自身",FiLM | 60 | 比 V13 低 7;sink 实测只扣 8.1% 权重,近乎常数,没起到选择作用 |
| V16 HBAR | 共识候选 + 分带注入 + margin 门控 | 63 | 比 V13 低 4(0 救 4 伤,p=0.125);donor 检验也过不了(+5,p=0.44) |
| V13+ | span 值、上下文扩散、CSLS | 65 | 低 2,donor 57 |
| V13+evicted | 把被删块内容也作为条件 | 64 | 低 3,donor 56 |

这些变体的共同教训:往校准器里加结构,没有一个超过 V13 简单版。继续堆结构不再值得。

### V17:不训练的评测(2026-11-15)
- density:V13 的 1,620 个 core 槽按块内冗余重新分配配额,不训练。结果 66,对 V13 为 0 救 1 伤(p=1.0),等同无效果。
- absorb:显存不足(OOM)失败,未得到结果。
- attn_q50 / attn_q90:冒烟测试失败,报 `KeyError: 'V17'`,评测脚本的臂注册有问题,未得到结果。

## 四、当前判断

1. **能写进论文的**:相同容量下,"淘汰 + 全池残差校准"让 HotpotQA 158 题从基线 35/41 提到 61 到 67;
   换成别人的 graft 内容会掉 13 题,说明收益依赖真实搬入的内容。
2. **还不能写进论文的**:"跨块融合"这个机制说法。邻居消融没有显著差别,而早期实验 2 已证明收益不来自候选内容。
3. **LongBench v2**:V10 没有测到涨点,reader 对正确选项的概率约 0.24,与随机持平。V13 还没有在 LongBench v2 上跑过。
4. **后续优先级**(按价值排序):
   1. 在独立自然多跳数据集(如 2WikiMQA、MuSiQue 验证集)上验证 V13,不再用这 158 题选任何东西。
   2. 多 seed(至少 3 个),报告均值和区间。
   3. 邻居消融补全:`V13Bottom` 和 `V13Rand` 在更大样本上是否有显著差别;加一个"同容量、无条件分支"的对照。
   4. 把 V13 接到 LongBench v2 评测链(`eval_lbv2.py`)。
   5. 暂停 V14 以后的结构迭代。
